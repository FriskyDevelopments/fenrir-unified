## Integration corrections

The navigation-only Community handoff could send an anonymous Gate visitor back
without a Community session. Gate/login now use Community's own Supabase OAuth,
provider capabilities and callback persistence, preserving a sanitized Gate
destination and brand. Main continues to use Worker/Better Auth.

Community storage is scoped to the current origin and a Community-specific key.
It does not import, write or clear parent-domain Supabase cookies. Users whose
only saved session is in the legacy shared cookie must sign in to Community
again after deployment. This change has not been deployed.

Two main-branch Gate demo TypeScript errors were repaired (brand type import and
unsupported mascot style prop). Community's inconsistent lockfile was regenerated
and verified with a clean `npm ci`. Miniflare is an explicit pinned development
dependency for the D1 concurrency regression.
